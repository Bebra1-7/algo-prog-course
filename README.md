# ПР1. Ответы на контрольные вопросы
1. Компилируемый язык отличается от интерпретируемого тем, что компилир. язык ищет сразу ошибки, а интерпретир. по ходу работы кода находит их.

2. Как я понял, команда на первом шаге код переделывается в машинный, а на втором шаге запускается сам код. 
3. В obj хранятся временные файлы, т. е. в obj переводится наш код в двоичный, а в bin готовый двоичный файл проекта. Я думаю, что эти папки не надо хранить в Git, потому это увеличивает размер всего проекта и могут быть проблемы с безопасностью.
4. commit — оставляет коментарий правее папки. push — меняет данные прошлой версии файла, на новые.
5. через + мы складываем строки, а через $"" мы добавляем строки в какое-либо предложение. Предпочтительней интерполяция, она быстрее и удобнее.
6. Результатом станет целое число без округления(пример: 25/4 = 6). Иправить можно, просто изменив тип на десятичный(пример: double g = (double)25/4 #Эти числа были int).
7. const не изменяемый тип данных(пример: const t = 100 #Температура кипения воды).
8. В top-level statements не нужно объявлять класс и метод, можно писать сразу исполняемый код.
